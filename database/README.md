# Database

โฟลเดอร์นี้เป็นที่รวมไฟล์ฐานข้อมูลและ migration ทั้งหมดตามโครงใหม่

## โครงที่แนะนำ
- `schema/` - schema หลักของระบบ
- `migrations/` - ไฟล์เพิ่ม/แก้ไข schema ตามเวอร์ชัน
- `seeds/` - ข้อมูลเริ่มต้นหรือ mock data
- `install_all.sql` - ไฟล์ติดตั้งรวมแบบเรียกตามลำดับ

## สถานะตอนนี้
- ระบบเดิมยังมีไฟล์ SQL อยู่ใน `backend/` เพื่อความเข้ากันได้
- ไฟล์ในโฟลเดอร์นี้จะเป็นจุดหมายปลายทางสำหรับการย้ายต่อทีละขั้น
